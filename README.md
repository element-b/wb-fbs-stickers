# WB FBS Stickers

Streamlit-приложение для выбора WB FBS-поставок и получения оригинальных
стикеров сборочных заданий, сгруппированных по артикулу продавца.

Приложение не создаёт и не изменяет поставки, заказы или статусы.
Стикеры доступны только для подходящих статусов WB. Трансграничные
заказы в этой версии блокируют формирование файла.

## Streamlit Secrets

Добавьте в настройках приложения Streamlit Community Cloud:

```toml
WB_API_TOKEN = "токен"

[users]
kladovshik = "уникальный_пароль"
